# DeepSeek Peak Hours — расширение для Chrome

Показывает **пиковые и офф-пиковые часы API DeepSeek** в часовом поясе пользователя, чтобы не платить вдвое больше за то же самое. Расписание и цены расширение **само перечитывает с официальной страницы тарифов раз в неделю**.

Тарифы DeepSeek зависят от времени: в офф-пик цена **вдвое ниже** ([официальные тарифы](https://api-docs.deepseek.com/quick_start/pricing)):

> Off-peak rates are half of the peak rates. Peak hours are **01:00–04:00 и 06:00–10:00 UTC, Пн–Пт** (всё остальное время — офф-пик).

## Что делает

| Элемент | Поведение |
| --- | --- |
| Иконка | Зелёная полоса под логотипом — офф-пик (−50%), красная — пик. Обновляется в момент смены тарифа. |
| Бейдж | `OFF` на зелёном или `PEAK` на красном. |
| Подсказка при наведении | Тариф и сколько осталось до смены: «…офф-пик — скидка 50%, до пика 2 ч 14 мин». |
| Popup | Крупный статус, часы (ваши и UTC), отсчёт до смены тарифа, полоса 24 часов суток, пиковые окна в вашем поясе, таблица цен, источник данных и кнопка «Обновить данные». |
| Часовой пояс | Логика считается в UTC (как у DeepSeek), отображается в вашем поясе — переход на летнее время ничего не ломает. |
| Актуальность | Раз в неделю скачивается страница тарифов: часы пиков, дни недели, размер скидки и цены. |

## Экономия ресурсов

Расширение намеренно редко просыпается:

| Что | Как часто |
| --- | --- |
| Смена иконки/бейджа | Одноразовый alarm **ровно на момент смены тарифа**: 2–4 пробуждения в сутки (в выходные — ноль). Раньше был минутный таймер, то есть 1440 пробуждений service worker'а в сутки. |
| Проверка страницы тарифов | Раз в неделю (при сбое — повтор через 12 часов, но не чаще). |
| Popup | Тик раз в 30 секунд, только пока окно открыто. Секунды из отсчёта убраны — секундный таймер ничего не давал, кроме лишней работы. |

## Установка

1. Chrome → `chrome://extensions`.
2. Включить **Режим разработчика** (справа сверху).
3. **Загрузить распакованное расширение** → выбрать папку с `manifest.json`.
4. Иконка появится на панели; закрепите её, чтобы видеть статус постоянно.

Разрешения: `alarms`, `storage` и доступ к `https://api-docs.deepseek.com/*`. Сеть используется только для чтения публичной страницы тарифов; наружу ничего не отправляется.

## Как работает обновление данных

1. Раз в неделю (или сразу после установки) service worker скачивает страницу тарифов.
2. `src/parse-pricing.js` разбирает её: фразу `Peak hours are 01:00 - 04:00 and 06:00 - 10:00 UTC, Monday through Friday` и таблицу цен.
3. Данные проверяются на правдоподобность (интервалы, дни недели, «пик дороже офф-пика», число цен = число моделей) и сохраняются в `chrome.storage.local`.
4. Если разбор не удался — **остаются прежние данные**, а в popup появляется пометка, что используется файл расширения; повтор через 12 часов.
5. В popup видно источник: «Данные с сайта DeepSeek · проверено 18.09.2026» (зелёным) или предупреждение (красным). Кнопка «Обновить данные» перечитывает страницу принудительно.

Парсер ничего не угадывает: если формулировка или таблица изменились так, что распознать не удалось, он сообщает причину, а расширение продолжает работать на последних проверенных данных.

## Изменить значения вручную

Встроенные значения (используются, пока страница не скачана, и как страховка) — в `src/schedule.js`:

```js
export const BUNDLED_SCHEDULE = {
  peakWeekdaysUtc: [1, 2, 3, 4, 5],                 // Пн–Пт
  peakWindowsUtc: [
    { startMinute: 60, endMinute: 240 },            // 01:00–04:00 UTC
    { startMinute: 360, endMinute: 600 },           // 06:00–10:00 UTC
  ],
  discountPercent: 50,
};
```

Цены — в `BUNDLED_PRICES` там же. Если DeepSeek поменяет тарифы, достаточно дождаться недельного обновления — или нажать «Обновить данные» в popup.

## Тесты

```bash
npm test          # 7 наборов: расписание, парсер, обновление, иконки, манифест, фолбэк иконки, popup
npm run icons     # перегенерировать PNG-иконки
npm run fixture   # обновить сохранённую копию страницы тарифов для тестов
```

Отдельно проверяется в том числе: границы окон (03:59 — пик, 04:00 — уже нет), выходные как сплошной офф-пик, пропуск выходных при поиске смены тарифа, перевод окон в московское время (04:00–07:00 и 09:00–13:00), разбор реальной страницы, отказ при нераспознанной формулировке, сохранение прежних данных при сбое сети, отсутствие минутного alarm и секундного тика.

## Если в консоли видно `Failed to set icon ... Failed to fetch`

Это известная флакость Chrome: `chrome.action.setIcon({ path })` из service worker иногда не может загрузить PNG — чаще всего один раз при старте/обновлении воркера. Расширение обрабатывает это само:

1. повторная попытка через 300 мс;
2. если путь недоступен и тогда — иконка собирается в `imageData` через `OffscreenCanvas` из тех же PNG, и этот режим закрепляется на время жизни воркера (в консоли появляется одно `console.info` о переключении);
3. бейдж `OFF`/`PEAK` и подсказка при наведении выставляются **независимо** от иконки.

## Пример экономии

Модель `deepseek-flash`, выход: $1.20 / 1M токенов в пик против $0.60 в офф-пик. Прогон на 50M выходных токенов: **$60 в пик против $30 в офф-пик**. Для `deepseek-v4-pro` — $198 против $99.

Практический приём: тяжёлые пакетные задачи (рефакторинги, генерация документации, ночные прогоны тестов) ставить на офф-пик — по Москве это будни до 04:00, 07:00–09:00 и после 13:00, а также все выходные.
